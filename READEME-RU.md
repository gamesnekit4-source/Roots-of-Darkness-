# ⚔️ Корни Тьмы: Эхо Падших Королей

**Корни Тьмы: Эхо Падших Королей** — мрачная фэнтезийная roguelike-игра, в которой игрок исследует процедурно генерируемые подземелья, сражается с монстрами и боссами, собирает артефакты и постепенно создаёт собственную боевую сборку.

Каждый забег — новое испытание. Комнаты, противники, предметы и комбинации способностей заставляют менять тактику, экспериментировать с экипировкой и искать собственный стиль прохождения.

Проект вдохновлён атмосферой тёмного фэнтези и механиками таких жанров, как roguelike, dungeon crawler и action RPG.

## 🌑 Об игре

Мир пал под властью древних сил. Двенадцать этажей отделяют героя от финального испытания, а каждый следующий уровень становится опаснее предыдущего.

Игроку предстоит исследовать комнаты, сражаться с противниками, находить сокровища, покупать полезные предметы у торговцев и побеждать боссов. Смерть — часть прохождения: каждый новый забег позволяет попробовать другую комбинацию предметов и способностей.

Главная цель — пройти все 12 этажей, победить финального босса и испытать свои силы в последующих циклах повышенной сложности.

## ✨ Основные особенности

- **12 этажей и несколько тематических локаций** с различающимися противниками и испытаниями.
- **Исследование подземелий:** комнаты с врагами, сокровищами, ловушками, торговцами и боссами.
- **Сражения в реальном времени** с уклонениями, различными атаками и активными способностями.
- **Множество предметов и артефактов**, меняющих характеристики и стиль игры.
- **Редкости предметов:** разные уровни ценности и силы экипировки.
- **Мини-боссы**, которые могут неожиданно появиться в подходящих комнатах.
- **Сундуки с наградами** после завершения боевых столкновений.
- **Древо талантов:** развитие персонажа за красные кристаллы в течение забега.
- **Креативная лаборатория:** эксперименты с предметами, противниками, боссами и характеристиками.
- **New Game+:** повторное прохождение с усиленными противниками.
- **Мини-карта** для навигации по исследованным комнатам.
- **Система сохранений** с возможностью экспорта и импорта данных.
- **Звуковые эффекты и процедурно создаваемая музыка.**

## 🧙 Игровые персонажи

В игре представлены персонажи с разными особенностями и подходами к прохождению.

| Персонаж           | Особенность                                                     |
| ------------------ | --------------------------------------------------------------- |
| Странник           | Стандартный герой для знакомства с игрой                        |
| Архитектор         | Настройка характеристик и лимита предметов                      |
| Последний          | Начинает с 1 HP, случайного усиления и дополнительных предметов |
| Бандит             | Использует отдельные монеты-жизни, выпадающие с противников     |
| Сумрачный стрелок  | Повышенные скорость и урон, но ограниченная видимость           |
| Алекс              | Сражается с помощью ближней ауры и летающих снарядов            |
| Звёздный изгнанник | Использует усиливающиеся пробивные выстрелы                     |

У каждого героя свой стиль игры. Выбор персонажа влияет на тактику боя, полезность предметов и сложность прохождения.

## 🗡️ Предметы и сборки

Предметы — одна из центральных механик игры.

Они могут:

- увеличивать здоровье, скорость, силу и другие характеристики;
- изменять поведение атак;
- добавлять дополнительные снаряды и стихийный урон;
- создавать защитные эффекты и вспомогательных существ;
- давать активные способности;
- восстанавливать здоровье или усиливать героя при определённых условиях;
- взаимодействовать друг с другом, создавая необычные комбинации.

Обычные персонажи ограничены десятью предметами. Архитектор может изменять лимит через настройки своего персонажа.

Некоторые предметы обладают активными эффектами и требуют отдельного действия игрока.

## 👹 Боссы и прогрессия

На ключевых этапах прохождения игрок встречает боссов с уникальными атаками и несколькими стадиями сражения.

По мере продвижения:

- противники становятся опаснее;
- увеличиваются характеристики врагов;
- появляются новые угрозы и более сложные комбинации атак;
- награды позволяют создавать более сильные сборки.

После победы над финальным боссом можно начать новый цикл New Game+ с усиленными противниками.

Также существует механика спасения после смерти: при определённых условиях герой может получить шанс на возвращение в забег, потеряв часть предметов.

## 🧪 Режим испытаний

Креативная лаборатория предназначена для экспериментов и тестирования игровых механик.

В ней можно:

- находить предметы через поиск;
- проверять различные сборки;
- создавать противников и вызывать боссов;
- тестировать урон на манекене;
- экспериментировать с характеристиками героя;
- изучать взаимодействия предметов и способностей.

Поиск и выдача любых предметов относятся к режиму испытаний и не предназначены для обычного прохождения.

## 💻 Установка и запуск

Игра распространяется как HTML-проект с JavaScript и CSS. Для запуска основного игрового процесса не требуется компиляция C++.

### Вариант 1. Скачать через GitHub

1. Откройте страницу репозитория.
2. Нажмите **Code → Download ZIP**.
3. Распакуйте архив в удобную папку.
4. Откройте папку проекта.
5. Запустите `index.html` в современном браузере.

Если в проекте используется Windows-запускатель, можно попробовать `Korni_Tmy.exe` или `START_GAME.bat`. Файл `index.html` и остальные необходимые ресурсы должны оставаться на своих местах.

### Вариант 2. Скачать через Git

Если Git установлен, выполните:

```bash
git clone https://github.com/ВАШ-АККАУНТ/ВАШ-РЕПОЗИТОРИЙ.git
cd ВАШ-РЕПОЗИТОРИЙ
```

Затем откройте `index.html` в браузере.

Замените `ВАШ-АККАУНТ/ВАШ-РЕПОЗИТОРИЙ` на адрес своего репозитория.

### Если игра не запускается

- Убедитесь, что архив полностью распакован.
- Проверьте, что `index.html` находится в папке проекта.
- Попробуйте актуальную версию Chrome, Edge или Firefox.
- Если запуск из файла вызывает проблемы с сохранениями или загрузкой ресурсов, запустите локальный сервер из корневой папки проекта:

```bash
python -m http.server 8000
```

После этого откройте в браузере:

```text
http://localhost:8000
```

Для последнего способа должен быть установлен Python.

## 🎮 Управление

Основные клавиши:

| Клавиша | Действие                      |
| ------- | ----------------------------- |
| `W`     | Движение вверх                |
| `A`     | Движение влево                |
| `S`     | Движение вниз                 |
| `D`     | Движение вправо               |
| `E`     | Подобрать предмет             |
| `Esc`   | Пауза и экран персонажа       |
| `T`     | Открыть древо талантов        |
| `F2`    | Открыть лабораторию испытаний |

Атаки, активные предметы и дополнительные действия могут зависеть от текущих настроек управления. При необходимости проверьте подсказки внутри игры.

### 📱 Игра на телефоне

В настройках предусмотрен переключатель мобильного управления с сенсорными элементами управления.

Для игры на телефоне откройте страницу игры в мобильном браузере. Если проект размещён на GitHub Pages, можно использовать опубликованную страницу репозитория.

## 💾 Сохранения

Игра использует локальное хранилище браузера. Прогресс может быть привязан к конкретному браузеру и устройству.

Чтобы сохранить резервную копию:

1. Откройте меню сохранений.
2. Используйте экспорт сохранения.
3. Сохраните JSON-файл в надёжном месте.

Для переноса прогресса на другое устройство воспользуйтесь импортом этого файла.

**Важно:** очистка данных браузера может удалить локальное сохранение. Рекомендуется регулярно делать резервные копии.
